# 综测小助手

帮同学自动核算综合测评（综测）分数的 Web 应用：录入活动和证书 → 按学院评分细则自动算分 → 一键生成综测表。

我的第一个从 0 到上线的全栈项目，用于练习 AI 协作开发（vibe coding）的完整流程：需求卡片 → 小步切片 → 逐项验收。

**线上地址**：http://47.112.8.28:3000

## 功能

**免登录就能用（主路径，不需要账号）**

打开链接 → 填基础分 → 录几条活动 → 看五育和总分 → 导出官方综测表。

- 不填学号、不填姓名，数据存在浏览器 localStorage，不上传服务器
- 五育基础分登记：德育 / 智育 / 体育 / 美育 / 劳育，含互评分与扣分
- 录入活动：育别 → 条目 → 级别 → 等级四级联动，支持关键词搜索细则、按量计分（如志愿服务按小时）
- 活动列表：按育别筛选、小计、行内编辑、删除二次确认
- 综测总分：五育折算分 + 综合总分（德20% 智60% 体10% 美5% 劳5%）
- 导出：官方综测表 Word（可提交）+ 核对用 Excel，**在浏览器里生成，文件不经过服务器**
- 评分细则：224 条全部可查可搜（只读）

**注册之后多出来的（可选）**

- 数据存到服务器：换手机、清缓存都不丢
- 试算时录的内容可以一键导入账号
- 专业内排名、跨设备查看
- 修改密码：校验旧密码，改完踢掉其他设备会话；忘记密码提示联系管理员

**管理员（班委）**

- 规则配置：224 条真实细则，分值 / 常见例子（搜索关键词）/ 备注均可改，改完立即生效（其他角色只读）
- 成员管理：查看全班成员（手机号脱敏），一键重置某人为临时密码 `zc+学号`，该生所有设备立即下线且下次登录必须先改密
- 全班排名：五育折算分 + 总分排序，按班级筛选，同分并列取靠前名次

**通用**

- 手机端：触控目标 ≥44px、输入框 16px（iOS 不放大）、正文字号 ≥13px，320px 宽度可用
- 无横向滚动条，深色 / 浅色系统下均为浅色可读主题

## 技术栈

- **框架**：Next.js 16（App Router）+ TypeScript
- **样式**：Tailwind CSS
- **数据库**：SQLite（better-sqlite3 12.4.1，224 条真实细则入库）
- **导出**：docxtemplater（官方 Word 模板 57 个占位符）+ exceljs，**前端生成**，按需动态加载
- **数据层**：双轨——登录走 `/api/*` + SQLite；免登录走 localStorage，算分逻辑前后端共用 `score-core.ts`
- **部署**：阿里云 ECS（深圳），systemd 托管，IP 直连免备案

## 已知限制

- 手机号唯一性目前只在接口层校验，未建数据库唯一索引（并发注册理论上可撞）
- 细则里"学年累计不超过 X 分"这类数量型封顶**尚未在算分中执行**，只在备注里展示
- 无短信 / 邮件验证码通道，忘记密码需管理员在成员管理页重置
- 一个库默认按"全部学生"排名，多班时靠班级筛选区分
- 免登录模式数据只在当前浏览器：换设备 / 清缓存就没了（注册后可导入账号）
- 免登录时没有专业名次（不掌握全班数据）；导出用的姓名学号在导出前临时填，不存库
- 手机端总分页约 2 屏，明细未做折叠合并（评估后决定暂不优化，避免数字挤在一起）

## 本地运行

```bash
npm install
npm run db:init     # 首次需要，建库 + 导入 224 条细则
npm run dev
```

打开 http://localhost:3000 查看效果。
